# Adebayo. W Portfolio (flat version)

A static website: no build step, no dependencies.
Every file sits in the same folder: `index.html` plus the images (logo.png, adebayo.jpg, favicon.png and the project mockups).

## Put it on GitHub
1. Open your repository on github.com and choose **Add file > Upload files**.
2. Drag in ALL the files from this folder (`index.html` and every image), replace the old ones, and commit.

## Deploy on Vercel
- If the repository is already connected to Vercel, it redeploys by itself after the commit.
- If not: on vercel.com choose **Add New > Project**, import the repository, set the Framework Preset to **Other**, leave the build command empty, and deploy.

Keep `index.html` and the images together at the top level of the repository.
